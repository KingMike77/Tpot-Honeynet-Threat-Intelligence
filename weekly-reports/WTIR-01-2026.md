## Executive Summary

This is the first weekly threat intelligence report for the T-Pot Honeynet, covering the initial deployment period from May 29 to May 31, 2026. Within hours of going live the honeynet began attracting real-world attacker traffic from across the globe. Over 65,000 attacks were captured across 10+ honeypot services during this period. Three distinct campaigns were identified and profiled: an automated MySQL database ransomware operation, and two concurrent VoIP toll fraud campaigns targeting SIP port 5060. All three source IPs appear on multiple reputation and threat intelligence feeds.

| Honeypot | Dionaea |
| Protocol/Port | MySQL TCP 3306 |
| IP Reputation | Known Attacker |
| Threat Intel Sources | Multiple (HIGH severity) |
| Campaign Type | MySQL Database Ransomware |

### Analysis

This source IP was the most active of the week with 19,225 connection attempts all aimed at MySQL port 3306. The behavior matches a well-known automated attack where a bot scans the internet for exposed MySQL databases, tries to log in using default or empty passwords, deletes the database if it gets in, and leaves behind a ransom note demanding cryptocurrency to restore the data. The IP shows up in Taiwan based on location data but the network it belongs to traces back to a Romanian hosting provider called Feo Prest SRL (AS208137). Infrastructure within this network has appeared on multiple threat intelligence feeds repeatedly. Nearly the entire surrounding IP range has 297 addresses flagged across threat intelligence sources, which suggests this is a block of addresses used regularly for malicious activity rather than a one-off incident.

### Analysis

This source IP made 6,801 connection attempts against SIP port 5060. SIP is the protocol that powers most internet-based phone systems. Attackers who find an exposed SIP server can hijack it to make thousands of international calls that get billed to the victim. The IP is hosted on OVH SAS (AS16276), a large French cloud provider that is frequently used for attack campaigns because servers there are cheap and easy to set up. This address shows up on 6 separate threat intelligence feeds at HIGH severity, including UCEPROTECT Level 1 which is the highest confidence tier on that blacklist, and the VoIP Blacklist which specifically tracks addresses known for phone system abuse.

## Notable Credential Intelligence (Cowrie)

Cowrie SSH honeypot captured credential data from an active brute force campaign consistent with a cryptocurrency mining botnet. The username and password patterns reveal targeted attempts against Solana validator and Ethereum node infrastructure.

Top usernames attempted: sol, solana, root, ubuntu, admin, ethereum, raydium, solnode, firedancer, postgres

Top passwords attempted: 12345678, 123456, solana, sol, 1q2w3e4r, admin, ubuntu, 123, node, 1234

The prevalence of crypto-themed credentials suggests an automated campaign specifically targeting exposed Linux servers running cryptocurrency validator nodes. Upon successful compromise these bots typically deploy mining malware or attempt to access associated hot wallets.

## Recommendations

Consider blocking AS208137 (Feo Prest SRL) and the 213.209.159.0/24 subnet at the perimeter given that 297 IPs in the same netblock appear on threat intelligence feeds. Consider blocking the 172.110.223.0/24 subnet given that 266 IPs in the same block are flagged across multiple feeds. MySQL port 3306 should never be exposed to the public internet and should always be bound to localhost or restricted via firewall rules. SIP port 5060 should not be exposed without strong authentication and connection rate limiting in place. Subscribing to VoIPBL and UCEPROTECT feeds can enable proactive blocking of known VoIP attack infrastructure. Monitoring for crypto-themed SSH credential patterns can serve as an early indicator of cryptocurrency infrastructure targeting campaigns.

## Intelligence Assessment

The first 72 hours of data suggests these were not targeted attacks against this specific system but rather automated bots scanning the entire internet looking for any vulnerable system they could find. The attackers were not targeting this honeynet in particular. They were scanning the entire internet and this IP happened to respond. The focus on SIP, MySQL, and SSH reflects the fact that these are common services that are often left exposed with weak or default passwords, making them easy targets for automated tools. The speed at which attack traffic appeared after going live shows how quickly automated scanners find new internet-connected systems. The fact that multiple unrelated campaigns showed up at the same time targeting different ports is a good example of the constant background noise of malicious scanning that every public-facing system faces.
